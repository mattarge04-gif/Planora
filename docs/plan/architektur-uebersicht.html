3 · Ablauf: Gebäude erfassen (Upload → KI → Bestätigung)

Die KI schlägt nur vor. Erst was ein Mensch bestätigt, erscheint als gültiger Wert im 3D und in der Lebensdauer-Rechnung.

sequenceDiagram
  autonumber
  participant B as Browser
  participant A as api
  participant S as Speicher
  participant W as worker
  participant D as docproc + ClamAV
  participant K as Claude (EU)
  participant P as PostgreSQL
  B->>A: POST /dokumente/upload
  A->>P: dokument status=hochladen
  A-->>B: einmalige Upload-URL (Quarantäne)
  B->>S: Datei hochladen
  B->>A: POST /dokumente/{id}/upload-fertig
  W->>D: Virenscan + Prüfsumme (gleiche Bytes)
  W->>S: nach dok/ kopieren, Vorschau-PDF erzeugen
  W->>D: OCR + Text und Tabellen je Seite
  W->>P: dokument_seite + Suchabschnitte + Embeddings
  alt KI für Mandant aktiv
    W->>K: Dokumentart, dann Auslesen (nur Katalog-IDs)
    W->>P: Prüfer: Zitat stimmt? Katalog passt?
    W->>P: angabe + element status=vorgeschlagen
  else KI aus
    W->>P: status=manuell_erfassen
  end
  B->>A: GET /pruefliste
  B->>A: POST /angaben/entscheiden (bestätigen / korrigieren)
  A->>P: angabe=bestaetigt, element_effektiv neu

4 · Ablauf: Klick im 3D → Dokument im Browser

Der Kern von V1. Das Dokument öffnet sich im Seitenpanel, ohne Download, auf der richtigen Seite mit markierter Stelle.

sequenceDiagram
  autonumber
  actor FM as Facility Manager
  participant B as Web-App (3D)
  participant A as api
  participant P as PostgreSQL
  participant S as Speicher
  FM->>B: Gebäude öffnen
  B->>A: GET /gebaeude/{id}/szene
  A->>P: Geschosse, Räume, Elemente, Ampel
  A-->>B: kompakte Szene (Rechtecke, Katalog-IDs, Pins)
  B->>S: 3D-Modelle (GLB, im Cache)
  FM->>B: Klick auf Monoblock
  B->>A: GET /elemente/{id}
  A-->>B: Kennwerte + Herkunft + Restlebensdauer + Dokumente
  FM->>B: Klick auf "Quelle: Datenblatt S. 1"
  B->>A: GET /dokumente/{id}/vorschau?seite=1
  A-->>B: kurzlebiger Link (5 min, nur dieser Mandant)
  B->>S: PDF seitenweise laden
  B-->>FM: PDF.js zeigt Seite 1, Zitat gelb markiert

6 · Zustände eines Dokuments

stateDiagram-v2
  [*] --> hochladen
  hochladen --> quarantaene: Upload fertig
  quarantaene --> abgelehnt: Virus / falscher Typ
  quarantaene --> geprueft: Scan ok
  geprueft --> aufbereitet: OCR, Text, Vorschau, Suchindex
  aufbereitet --> ki_laeuft: KI aktiv
  aufbereitet --> manuell_erfassen: KI aus
  ki_laeuft --> vorgeschlagen: Werte ausgelesen
  ki_laeuft --> fehler: nach 3 Versuchen
  fehler --> aufbereitet: neu starten
  vorgeschlagen --> erledigt: alles entschieden
  manuell_erfassen --> erledigt
  abgelehnt --> [*]
  erledigt --> [*]

7 · Datenmodell: alle Datenpunkte

8 · API (REST, /api/v1)

Jede schreibende Anfrage schickt die erwartete version mit. Bei einem Konflikt antwortet die API mit 409 und dem aktuellen Stand. Der Mandant kommt immer aus der Sitzung, nie aus der URL.
