# Track C4 – Leitungen je Heizgruppe (GPU-Bilder)

Szenario `werkzeug/design/szenarien/twin-gruppen.json`, eigene Instanz Port 3200/54700 (3100 war belegt), RTX 3070 Ti / D3D11, 60 fps in allen drei Fenstern. Nur bekannte Bibliotheks-/Shaderwarnungen, keine CSP-Verletzung.

- `m2…m6-uebersicht|technik|zentrale`: Mustergebäude 2–6, Übersicht, Technikgeschoss, Nahaufnahme Verteiler mit Gruppenabgängen.
- `m3-gruppenstock`: Pumpen, Ventile übereinander auf dem Abgang; `m3-gruppe-hover|gewaehlt`: Gruppe gewählt, übrige Leitungen treten zurück, Gruppenkarte mit Schaltung, Bestückung, Verbrauchern (Klickpunkt für 1440×900 bestimmt, in anderen Fenstern evtl. ohne Treffer).
- `m4-pumpe-vor-wp`: Pumpe sitzt in der Anschlussleitung der Wärmepumpe.

Offen: visual-critic-Runde, PO-Sichtung. Hauptleitungen Erzeuger→Speicher→Verteiler (bisherige Führung) bilden über der Zentrale auffällige Schleifen.
