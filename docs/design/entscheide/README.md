# Design-Entscheide

Eine Datei je groesserer Designaufgabe: `<JJJJ-MM-TT>-<thema>.md`, erstellt vom `art-director`, PO-Entscheid vom Hauptagenten nachgetragen. Optionale Schnellentwuerfe in `<JJJJ-MM-TT>-<thema>/` (nur lokale Dateien).

## Vorlage

```markdown
# <Thema> – Design-Entscheid

Datum, Auftrag (Brief in 3–5 Saetzen), betroffene Ansichten, Einstufung: klein | mittel | Richtungswechsel

## Ansatz A – <Name>
- Leitidee (1 Satz):
- Eigenstaendig daran:
- Tokens: Farben (4–6 Hex), Typo-Rollen, 3D-Material/Licht, Bewegung
- Skizze (ASCII-Wireframe / Szenenskizze):
- Risiken / Machbarkeit:

## Ansatz B – ...
## Ansatz C – ... (optional)

## Bewertung (1–5)
| Kriterium | A | B | C |
|---|---|---|---|
| Gestaltungsqualitaet | | | |
| Eigenstaendigkeit | | | |
| Referenz-Qualitaetsrichtung | | | |
| Produktanforderung / Lesbarkeit | | | |
| Machbarkeit / Leistung | | | |
| Aufwand (5 = gering) | | | |

## Empfehlung
## Regelvorschlag (PO-Bestaetigung noetig) – optional
## PO-Entscheid (vom Hauptagenten nachgetragen)
Datum, gewaehlter Ansatz, Abweichungen, Zitat des PO.
```
